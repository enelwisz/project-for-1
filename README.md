# CyberRunner AI

2D-аркада и тактическая головоломка на Python (PyQt6). 

Вместо привычного управления со стрелок игрок задает точку назначения кликом мыши на карте. Робот сам прокладывает кратчайший маршрут по сетке (используется алгоритм BFS/A*) и едет к цели. Основная сложность — на карте есть три быстрых патрульных бота, которые двигаются по фиксированным маршрутам. При столкновении с ними уровень начинается заново, поэтому приходится рассчитывать тайминги и делать промежуточные остановки.

## Что внутри
- Поиск кратчайшего пути по матрице уровня с отрисовкой маршрута.
- Игровой цикл на `QTimer` (60 FPS) и кастомная отрисовка поля через `QPainter`.
- Хранение карт уровней и таблицы рекордов (время прохождения + количество кликов) в SQLite.
- Весь код собран в одном файле `main.py` для простоты запуска и чтения.

## Запуск проекта

1. Склонировать репозиторий и перейти в папку:
```bash
git clone https://github.com
cd project-for-1
```

2. Установить PyQt6:
```bash
pip install -r requirements.txt
```

3. Запустить игру:
```bash
python main.py
```

При первом запуске рядом с `main.py` автоматически создастся файл базы данных `game_data.db` со стартовыми уровнями.

## Управление
- **ЛКМ по свободной клетке** — отправить робота в эту точку.
- Цель — добраться до зеленой клетки финиша за минимальное время и с меньшим числом кликов, не попавшись патрульным.
